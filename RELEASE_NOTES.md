# Release v1.0.0

## Summary
Public release of the Portfolio site. Highlights:

- Added MediWay Hospital Management System project (Sept–Oct 2025) with PayPal integration, role-based access, QR-based patient cards, and CI/test coverage.
- Fixed GSAP/ScrollTrigger memory leaks and added cleanup across sections to improve performance during fast scrolling.
- Throttled Navbar scroll handler to reduce re-renders during rapid scrolls.
- Added responsive hero improvements (planet scaling) and performance-focused WebGL settings.

## Details
- MediWay: Full-stack app (Spring Boot 3, Java 17, React 18, MySQL, Docker, PayPal, JUnit 5/Mockito). 484 tests, ~82% coverage.
- Performance: GSAP animations now properly killed on unmount; scroll handlers throttled.
- Deployment: Site deployed on Vercel — https://shalonfernando.vercel.app/; MediWay demo at https://medi-way.vercel.app/
